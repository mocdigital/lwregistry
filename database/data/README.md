# Location Dataset

`countries+states.json` is the states-only export from the public
`dr5hn/countries-states-cities-database` dataset.

Source: https://github.com/dr5hn/countries-states-cities-database

The upstream project publishes the data under the Open Database License (ODbL).
This app uses the bundled states-only JSON to populate the `states` table for
country-dependent registration dropdowns.
